# Folder gambar website

Simpan seluruh foto lokal di dalam folder ini. Gunakan subfolder berikut agar mudah dicari:

- `banners/` — banner utama dan banner halaman.
- `destinations/` — foto setiap destinasi wisata.
- `culture/` — foto budaya, tradisi, pura, dan kesenian.
- `general/` — logo, ikon, dan gambar umum.

Gunakan nama file sederhana, huruf kecil, tanpa spasi, misalnya `pura-uluwatu.jpg`. Foto yang disimpan di sini dapat dipanggil dengan URL `/images/nama-folder/nama-file.jpg`.
